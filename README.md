# Ethernova - Web 3.0 Blockchain Landing Page
Ethernova is a landing page website designed to introduce users to blockchain technology and decentralized systems. The website was developed as a final project for the **Human-Computer Interaction (HCI)** course.

## Purpose
The purpose of this project is to design and develop an informative and user-friendly landing page that introduces the fundamental concepts of blockchain technology and decentralized systems. This project also aims to apply Human-Computer Interaction principles in creating an engaging and intuitive web interface.

## Credits
The design and development of this project were inspired by the **Krypt - Web 3.0 Blockchain Application** tutorial by **JavaScript Mastery** and **Enyel Sequeira**. The original tutorial demonstrates the development of a Web 3.0 blockchain application using React, Solidity, and MetaMask. For this project, the original concept was adapted and simplified into a **landing page focused on introducing blockchain technology**, without the full blockchain transaction functionality of the original application.
